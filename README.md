## 📌 Overview

Code212 Desktop Manager is a desktop application built for the **Code212 university computer lab**. It provides a complete management system for lab desktops, student reservations, and employee administration — all through a clean Qt-based GUI.

---

## ✨ Features

- 🖥️ **Desktop Management** — Track and manage all lab computers
- 📅 **Reservation System** — Handle desktop reservations for students
- 🎓 **Student Management** — Add, update and manage student records
- 👨‍💼 **Employee Management** — Manage lab staff and their roles
- 🗄️ **Dual Database Support** — MySQL for production, SQLite for local use

## 🚀 Getting Started

### Prerequisites
- Qt Framework (>= 5.x)
- MySQL or SQLite
- C++ compiler (GCC / MSVC)

### Build & Run
1. Open the project in **Qt Creator**
2. Configure your database connection in the config file
3. Build and run the project
